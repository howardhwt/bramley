# Contributing to Bramley

Thanks for your interest in Bramley. Bramley is made by one person, so the most useful help right now is a good bug report.

## Reporting a problem

Open a [GitHub issue](https://github.com/howardhwt/bramley/issues) and include:

- Your Bramley version (Settings > About) and device (Brick or Brick Hammer).
- What you did, what you expected, and what happened.
- If it is a crash or a hang, the files in `.userdata/tg5040/logs/` on the card.

Search the existing issues first, in case it is already known.

## Ideas and pull requests

Open an issue before writing code, so we can agree it fits Bramley's design (an Apple-like system, Brick and Brick Hammer only, free and never sold). Keep each pull request to one fix or feature, and test it on a device.
